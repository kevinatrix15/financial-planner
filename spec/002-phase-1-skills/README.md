## Description

The Phase 1 skill suite for the Financial AI System — 10 Claude Code skills enabling structured financial reasoning with manual data entry (no local infrastructure required). Built around a standardized `financial-snapshot` input template used across all sessions.

## Skills in Scope

**Tier 1 — Foundation**
- `financial-snapshot` — master input template, used every session
- `quarterly-strategy` — big-picture prioritization
- `scenario-compare` — model specific decisions

**Tier 2 — Planning**
- `debt-strategy`
- `investment-review`
- `tax-optimization`
- `goal-modeling`

**Tier 3 — Tactical**
- `budget-diagnosis`
- `cash-flow-optimizer`
